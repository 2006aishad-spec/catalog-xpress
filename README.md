# ShopFlow Pro

PROMPT MESTRE PARA GERAR O SaaS COMPLETO



Quero que assumes o papel de uma equipa sênior composta por:



Product Manager



UI/UX Designer Senior



Full-Stack Developer Senior



Arquiteto de Software



Especialista em SaaS



Especialista em conversão e experiência do utilizador





O objetivo é criar um SaaS completo, moderno, funcional e pronto para produção para um sistema de catálogo digital com WhatsApp para lojas, com identidade visual futurista, forte lógica de produto e experiência premium.



Visão do produto



Criar uma plataforma SaaS para pequenos negócios venderem melhor sem precisar de e-commerce complexo.

O sistema deve permitir que cada loja tenha o seu catálogo online, com link próprio, produtos organizados, botão de compra via WhatsApp e área administrativa para gerir tudo.



O produto deve ser pensado para:



lojas de roupa



cosméticos



acessórios



telemóveis



papelarias



mini-mercados



negócios locais que vendem pelo WhatsApp





Objetivo principal



Ajudar o lojista a:



1. mostrar os produtos de forma profissional





2. receber encomendas rapidamente





3. organizar o catálogo





4. vender mais sem complicação técnica





5. ter um sistema fácil de usar no telemóvel







Tom do produto



Quero um sistema com aparência:



premium



futurista



minimalista



elegante



confiável



moderno



forte foco em conversão



preparado para mobile first





Direção visual



Cria uma interface com linguagem visual futurista, limpa e sofisticada.



Estilo visual



fundo escuro elegante



contrastes fortes



elementos luminosos sutis



gradientes refinados



cards com vidro, brilho leve ou efeito depth



animações suaves



cantos arredondados



ícones modernos



tipografia forte e legível



sensação de produto high-end





Inspiração visual



SaaS premium moderno



dashboards limpos



interfaces de startup tecnológica



estética futurista sem exagero



visual que pareça caro, inteligente e confiável





Paleta sugerida



preto carvão / azul noite como base



branco suave para textos



verde para sucesso e ação



azul elétrico ou ciano para destaque



amarelo discreto para alertas



vermelho apenas para erros





Requisitos de UX/UI



A experiência deve ser pensada para usuários com pouca familiaridade tecnológica.



Princípios



simplicidade extrema



navegação clara



fluxos curtos



botões visíveis



formulários rápidos



nada confuso



mobile-first



acessibilidade básica

Padrões UX

Estrutura do SaaS



Cria o sistema com estas áreas principais:



1. Landing page pública







Objetivo: vender o produto para lojistas.



Seções:



hero com proposta clara



problema e solução



benefícios



demonstração visual do catálogo



planos e preços



depoimentos fictícios ou placeholders se necessário



FAQ



CTA forte para começar



footer profissional





2. Página de login e registo







login por email e senha



opção de criar conta



recuperação de senha



design limpo e premium





3. Onboarding da loja







Depois do registo, guiar o utilizador para:



nome da loja



logo



cor principal



número de WhatsApp



descrição da loja



categoria do negócio



localização



moeda



horários de funcionamento





4. Dashboard principal







Mostrar:



vendas recebidas



produtos ativos



cliques no WhatsApp



visitas ao catálogo



produtos mais vistos



pedidos recentes



ações rápidas





5. Gestão de produtos







Permitir:



adicionar produto



editar produto



remover produto



upload de imagem



preço



desconto



categoria



stock



descrição



destaque



status ativo/inativo





6. Catálogo público da loja







Cada loja deve ter:



link personalizado



visual bonito



capa



nome da loja



descrição



categorias



produtos em grelha



botão “Comprar no WhatsApp”



pesquisa de produtos



filtros por categoria



visual mobile excelente





7. Pedidos / Leads







Mesmo que o pagamento seja via WhatsApp, o sistema deve registar:



produto clicado



hora



nome do cliente se fornecido



estado do pedido



origem do clique



notas internas





8. Personalização da loja







Permitir:



alterar tema



alterar cor principal



alterar banner



alterar logo



editar texto de apresentação



configurar mensagens automáticas





9. Planos e assinaturas







Criar lógica de SaaS com:



plano grátis limitado



plano básico



plano profissional





Cada plano pode limitar:



número de produtos



número de categorias



número de imagens



personalização



relatórios



marca própria



estatísticas





10. Área de administração







Para o dono da plataforma:



ver lojas cadastradas



aprovar ou bloquear lojas



gerir planos



ver métricas gerais



analisar uso



monitorizar atividade



editar conteúdo do site



gerir suporte
